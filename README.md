# Anonimato PDF

Anonimato PDF is a browser-only tool for finding and covering personal data and faces in PDF files. Processing happens locally. The application does not upload documents or require a backend.

The workspace accepts multiple PDF files in a persistent queue. Global anonymization options stay in the sidebar, while the selected document is reviewed one page at a time. Wide screens use three columns: the original page, an identically scaled anonymized PDF preview, and the detected-data register on the far right. On narrow screens the same reading order becomes a vertical stack.

The anonymized preview is rendered from the same MuPDF-generated bytes used by the download. Changing a selection invalidates the cached PDF and regenerates the preview, so the visible page matches the exported document.

Detection combines PDF text extraction, AcroForm value inspection, local Spanish/English OCR, format rules, checksum validation, and contextual heuristics. OCR covers scanned pages and text embedded in images. Supported structured identifiers include DNI, NIE, CIF, Spanish social-security numbers, Spanish IBANs, payment cards, phone numbers, email addresses, URLs, vehicle plates, and birth dates. Contextual detection covers names and addresses, including names outside the bundled dictionaries when they follow a strong field label or title.

Every replacement includes a confidence score. Review lower-confidence contextual detections carefully. Use **Ocultar zona** to drag an opaque manual redaction over anything the automatic detector misses.

Detected values are replaced by stable tokens such as `[NOMBRE 1]` and `[DNI 1]` by default. MuPDF applies destructive redactions to the affected PDF content and the replacement tokens are then baked into the page as real PDF content. They are not annotations hiding recoverable source text.

## Security model

- MuPDF applies destructive redactions to page content before replacement tokens are inserted.
- Replacement annotations are baked into ordinary page content and removed before saving.
- The output is fully rewritten with garbage collection, stream sanitization, compression, and no incremental history.
- Source annotations and AcroForm widgets are flattened before detection areas are redacted. Embedded files and common document metadata are removed.
- PDF.js JavaScript evaluation is disabled.
- Faces use opaque covers by default. Pixelation is available but provides weaker privacy.
- CSV and JSON logs omit original values by default and only include enabled replacements.
- Input is limited to 100 MB, 200 pages, 40 million pixels per page, and 180 million pixels per document.
- The local development server only binds to `127.0.0.1`, rejects paths outside the project, and sends restrictive browser security headers.

Automatic detection is not a guarantee of complete anonymization. A person must inspect every output page before sharing it. OCR is enabled by default, runs locally, and can still misread low-resolution, handwritten, rotated, or visually obstructed text.

## Requirements

- Node.js 22 or newer
- PowerShell 7 on Windows for the included development server
- Chrome, Edge, or Chromium for end-to-end tests

Set `PUPPETEER_EXECUTABLE_PATH` when the browser is installed in a non-standard location.

## Development

```powershell
npm ci
npm run vendor:sync
npm start
```

Open <http://127.0.0.1:8765/>.

Run all checks:

```powershell
npm test
npm run security:audit
```

## Updating browser dependencies

Update the npm packages, run `npm run vendor:sync`, and commit both the lockfile and generated files under `vendor/`. The face detection model is not provided by the npm package and must be reviewed separately. Its provenance and checksum are recorded in `THIRD_PARTY.md`.

## Known trade-offs

- Destructive PDF editing invalidates digital signatures and can alter complex forms, annotations, optional-content layers, or unusual page content.
- OCR adds processing time and can produce false positives or false negatives.
- Name and address recognition is heuristic and can produce false positives and false negatives.
- Face recognition can miss small, rotated, obscured, or stylized faces.
- Large documents can still require substantial memory within the documented limits.
